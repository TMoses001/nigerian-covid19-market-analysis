# Nigerian COVID-19 Market Regimes — Analysis Pipeline

## Project Overview
This project examines the impact of COVID-19 on Nigerian financial markets, using historical financial data from 2017 to 2025.

## Markets Analysed
- Brent crude oil prices
- Nigerian Exchange All-Share Index (NGX ASI)
- USD/NGN exchange rate
- Nigerian government bond yields

## Methods
- ARIMA time-series modelling
- GARCH(1,1) volatility modelling
- Principal Component Analysis (PCA)
- Correlation analysis
- Hidden Markov Model (HMM) market-regime detection
- Welch’s t-test and Levene’s test

## Tools
Python, pandas, NumPy, Matplotlib, seaborn, and relevant statistical modelling libraries.

## How to Run
1. Open the notebook in Google Colab.
2. Upload or connect the required CSV datasets.
3. Ensure the dataset file paths in the notebook are correct.
4. Run the notebook cells in order.

## Research Objective
To investigate changes in Nigerian financial market behaviour and volatility around the COVID-19 period.
